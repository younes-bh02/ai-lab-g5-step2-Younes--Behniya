# مدل داده استاندارد

## نمایش گراف
شبکه معابر به صورت گراف جهت‌دار وزن‌دار `G=(V,E)` نمایش داده می‌شود. جهت‌دار بودن برای رعایت مسیرهای یک‌طرفه ضروری است.

## Node
| فیلد | نوع | شرح |
|---|---|---|
| `node_id` / `osmid` | int یا str | شناسه گره |
| `x` | float | طول جغرافیایی |
| `y` | float | عرض جغرافیایی |

## Edge
| فیلد | نوع | شرح |
|---|---|---|
| `u` | int/str | گره شروع |
| `v` | int/str | گره پایان |
| `key` | int | شناسه یال موازی، در صورت استفاده از MultiDiGraph |
| `length` | float | طول بر حسب متر |
| `highway` | str/list | نوع راه |
| `oneway` | bool/str | وضعیت یک‌طرفه، در صورت وجود |
| `name` | str/list | نام خیابان، در صورت وجود |
| `access` | str | محدودیت دسترسی، در صورت وجود |
| `geometry` | LineString | هندسه راه، در صورت وجود |

## وزن
وزن پیش‌فرض الگوریتم `length` بر حسب متر است. همه وزن‌ها باید نامنفی باشند. زمان سفر تنها وقتی قابل استفاده است که سرعت/زمان معتبر و منبع آن مشخص باشد.

## موانع و تغییرات مصنوعی
موانع در یک لایه جداگانه نگهداری شوند، نه در داده خام OSM.

| فیلد | شرح |
|---|---|
| `scenario_id` | شناسه سناریو |
| `edge_ref` | ارجاع به یال یا یال‌های تحت تأثیر |
| `effect` | `closed` یا `penalty` |
| `penalty_factor` | ضریب افزایش وزن، فقط برای `penalty` |
| `description` | توضیح سناریوی فرضی |

برای `closed`، یال در نسخه سناریویی گراف غیرقابل عبور می‌شود یا از گراف سناریو حذف می‌شود. برای `penalty`، وزن افزایش می‌یابد و مقدار آن باید در گزارش ذکر شود.

## نکته OSMnx
شبکه OSMnx غالباً از نوع `MultiDiGraph` است؛ بین دو گره ممکن است چند یال موازی وجود داشته باشد. شناسه یال باید در صورت نیاز شامل `(u, v, key)` باشد، نه فقط `(u, v)`.
